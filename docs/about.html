Über die Toolbox

Hintergrundinformationen zur Sammlung, zum Datenschutz und zu externen Datenquellen.

Direkt im Browser

Die Toolbox ist eine wachsende Sammlung kleiner Rechen- und Alltagstools. Sie ist ohne Installation über GitHub Pages auf Desktop und mobilen Geräten nutzbar.

Datenschutz

Eingegebene Rechenwerte werden grundsätzlich lokal im Browser verarbeitet und nicht gespeichert. Einzelne Tools können öffentliche externe Daten laden; das wird auf der jeweiligen Rechnerseite ausdrücklich angegeben.

Live-Daten

Der Bundesschatz-Vergleich lädt aktuelle öffentliche Konditionen über einen schlanken Cloudflare-Worker-Proxy. Der Proxy speichert keine Zinssätze und enthält keine feste Laufzeitenliste.
